Github Sharer

Configure how content is extracted from GitHub and how it is formatted when copied to your clipboard.

Templates

Each template has a body with {{ fieldName }} placeholders and a list of URLs it applies to. When the popup opens, every template matching the page is offered. Newlines become <br> in the HTML copy; selector fields keep their markup, other fields are inserted as plain text.

Templates are offered in the popup on matching pages.

Fields

Each field has a name used in template bodies. Selector fields read the page DOM (trying selectors top to bottom), input fields show a dropdown in the popup, and URL fields read the page address.

Reference fields in a template body as {{ name }}.

Import / Export

Export your templates and fields to a JSON file, or import a previously exported configuration. Importing replaces the current configuration (remember to Save afterwards).

Importing replaces the current configuration.
